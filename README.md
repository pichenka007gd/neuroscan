# NeuroScan

Русскоязычный frontend-прототип лендинга ИИ-ассистента врача-рентгенолога. Vite, vanilla JavaScript и Three.js. Без backend.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`. Тесты: `npm test`.

По умолчанию `npm test` пропускает браузерные проверки. Для них: `VIEWER_URL=http://localhost:4173 SHOWCASE_URL=http://localhost:4173 REVISION_URL=http://localhost:4173 npm test` при запущенном preview; требуется локальная настройка Playwright с Firefox в `.verification`, не входящая в зависимости проекта.

## Что работает

- 3D-просмотр томографического объёма: автовращение по умолчанию, параллакс от курсора и ручное вращение перетаскиванием. Видимые кнопки паузы и сброса убраны; Space ставит вращение на паузу и возобновляет его.
- WebGL останавливается при уходе самой сцены с экрана, даже если нижние элементы управления ещё видны. Это исключает фоновый рендер при свайпах карточек.
- Наведение, фокус или нажатие на ROI останавливает объём и открывает оформленный черновик ИИ: миниатюра среза, посимвольный вывод и отклонение 18,6%. Это демонстрационный сценарий, а не медицинское измерение. Рамка состоит только из ярких углов.
- Полноширинная секция «Верните время врачу»: график накопленного времени за 60 исследований. Без ассистента — 600 минут, с ассистентом — 360 минут; разница — 240 минут в день, или 88 часов за 22 рабочих дня.
- Прозрачная модель учебного кейса: 10 минут на описание, условное снижение времени на 40%. Это не клинический результат и не прогноз. Линии и счётчик анимируются один раз при появлении графика; reduced-motion сразу показывает итог, постоянного цикла анимации нет.
- Линии графика и подписи у их концов выбираются наведением, фокусом, Enter/Space или касанием. Справа один показатель плавно меняется между 360 и 600 минутами, при reduced-motion переключается сразу. Отдельных кнопок-карточек нет.
- Нативная валидация формы и локальное уведомление «Макет: данные не отправлены». Отправки, backend и сохранения персональных данных нет.
- Адаптивная компоновка, навигация с клавиатуры, режим уменьшенного движения.
- Карточки трёх шагов: авторские SVG-листы раскрываются при наведении или фокусе, монохромные лучи ограничены областью иллюстраций, по контуру документов движется рамка. На точном указателе иллюстрация мягко следует за курсором; текст остаётся неподвижным.
- На телефоне три карточки образуют обычную горизонтальную ленту без зацикливания. Нативный scroll snap с `scroll-snap-stop: always` фиксирует соседнюю карточку; программных скачков прокрутки и копий нет. Иллюстрации появляются однократно, когда карточка видна больше чем наполовину.
- Фоновая передняя дуга 3D-кольца из 32 срезов, уходящая за края блока; задняя половина скрыта. При наведении появляется liquid-glass панель, вращение продолжается. Space приостанавливает движение; reduced-motion заменяет дугу статичной сеткой.
- Движение ползунка сравнения не прерывает вращение. Тексты первого экрана, CTA и лид-формы соответствуют требованиям презентации; общая пометка о демонстрации остаётся в подвале.
- Знак бренда имеет единый SVG-источник в `src/brand.js`; в шапке и подвале одинаковые квадратные пропорции. Иконки специальности и исследования не повторяют логотип.
- Секции разделены линиями. Блок безопасности занимает всю ширину: целевая схема серверов в РФ, разметка снимков врачами и проверка заключения специалистом. Числовые параметры обозначены как целевые, не как подтверждённые клинические результаты.

## Ограничения

Учебный концепт, не медицинское изделие. Проценты, скорость анализа и условия 14-дневного пилота взяты из задания, не подтверждены испытаниями. Томографическая визуализация и её разметка не предназначены для диагностики. VPN, обезличивание, размещение в РФ и документы описывают план внедрения, а не действующие гарантии. Не вводите реальные персональные или медицинские данные в форму.
