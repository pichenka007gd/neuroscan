# NeuroScan

Русскоязычный frontend-прототип лендинга ИИ-ассистента радиолога. Vite, vanilla JavaScript и Three.js. Без backend.

## Запуск

```sh
npm install
npm run dev
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`. Тесты: `npm test`.

## Что работает

- Интерактивный просмотр томографического объёма, сравнение с условной разметкой.
- Переключение сценария государственной и частной клиники.
- Калькулятор: исследования в день × 10 минут × 40% × 22 рабочих дня ÷ 60; результат округляется до часов.
- Нативная валидация формы и локальное уведомление «Макет: данные не отправлены». Отправки, backend и сохранения персональных данных нет.
- Адаптивная компоновка, навигация с клавиатуры, режим уменьшенного движения.
- Карточки трёх шагов: авторские SVG-листы раскрываются при наведении или фокусе. На точном указателе иллюстрация мягко следует за курсором; текст остаётся неподвижным.
- Лента шести реальных срезов локального демонстрационного объёма: однократная прокрутка при появлении, кнопки, клавиатура и свайп. Взаимодействие отменяет автопрокрутку; reduced-motion отключает её и движение от указателя.

## Ограничения

Учебный концепт, не медицинское изделие. Проценты, скорость анализа и условия 14-дневного пилота взяты из задания, не подтверждены испытаниями. Томографическая визуализация и её разметка не предназначены для диагностики. VPN, обезличивание, размещение в РФ и документы описывают план внедрения, а не действующие гарантии. Не вводите реальные персональные или медицинские данные в форму.
