# Tomography demonstration asset

`I.nrrd` is a real tomography volume downloaded on 2026-11-02 from the Three.js example asset:

https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/nrrd/I.nrrd

NRRD header: signed 16-bit voxels, 256 × 256 × 113, gzip encoding, voxel spacing 0.9375 × 0.9375 × 1.5 mm, left-posterior-superior coordinate space.

The source asset's individual license and original acquisition provenance have not been independently verified. Do not infer a medical-dataset license from the Three.js code license. Confirm redistribution rights before production publication.

Anatomy, imaging modality, and original acquisition details are not independently verified. The displayed cross-section appears abdominal; the viewer deliberately uses neutral tomography labels rather than claiming brain MRI or a specific acquisition sequence.

This prototype uses educational sample data. The highlighted region, model score (94.8%), and all AI-analysis annotations are synthetic interface demonstrations, not model inference, a diagnosis, or a probability of cancer. No patient upload, backend, or inference service is involved.
