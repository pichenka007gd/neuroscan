# Tomography slices

32 local PNG slices (`slice-12.png` through `slice-105.png`, step 3), extracted from `../data/I.nrrd`, 256 × 256 pixels. Displayed in a rigid rotating ring; front-card hover adds a glass overlay without pausing motion. Reduced motion presents a static grid.

See `../data/README.md` for source, provenance and unresolved dataset licensing. Old reference slices remain included for reproducibility. Images and annotations are demonstrations, not diagnostic findings.
