# Демонстрационные срезы

Шесть изображений извлечены из локального `public/data/I.nrrd`: срезы 24, 38, 52, 66, 80 и 94 из 113. Исходный источник и ограничения см. в `public/data/README.md`.

Извлечение: Three.js NRRDLoader, массив 256 × 256, разворот вертикальной оси, линейное отображение диапазона 0–1400 в 0–255 с ограничением; PGM преобразованы в PNG установленным ffmpeg. Это иллюстрации, не диагностические изображения. Модальность и анатомическая область не утверждаются. Мятные маркеры в интерфейсе условные.
